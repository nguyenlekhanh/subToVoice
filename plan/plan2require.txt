Required Implementation:

SUBTITLE MODEL (models/subtitle.py):
- Use @dataclass for clean structure
- Fields: index (int), start_ms (int), end_ms (int), text (str), voice (str, default="")
- No TTS or GUI functionality in model
- Proper __repr__ for debugging

SRT TIMESTAMP CONVERSION:
- parse_timestamp(timestamp_str: str) -> int: Convert "HH:MM:SS,mmm" to milliseconds
- format_timestamp(ms: int) -> str: Convert milliseconds to "HH:MM:SS,mmm"
- Handle edge cases: 0ms, exact hours, exact minutes, milliseconds padding

Examples:
"00:00:02,000" -> 2000
"00:01:05,500" -> 65500
"01:02:03,250" -> 3723250
0 -> "00:00:00,000"
1000 -> "00:00:01,000"
2500 -> "00:00:02,500"
60500 -> "00:01:00,500"
3723250 -> "01:02:03,250"

SRT LOADING (services/srt_service.py):
- load_srt(path: str) -> list[Subtitle]
- Parse standard SRT format with blocks separated by blank lines
- Handle UTF-8 with BOM support
- Handle multi-line subtitle text (preserve newlines)
- Read subtitle index from file (do not auto-renumber)
- Validate timestamps: start valid, end valid, end > start
- Raise clear errors for invalid data:
  - Missing timestamp line
  - Malformed timestamp
  - Missing arrow (-->)
  - Invalid start/end time
  - end_ms <= start_ms
  - Missing subtitle text
  - Invalid subtitle index

SRT SAVING (services/srt_service.py):
- save_srt(path: str, subtitles: list[Subtitle]) -> None
- Write valid SRT format with blank line between blocks
- Use UTF-8 encoding
- Preserve multi-line text with newlines
- Use format_timestamp for timestamps

MULTI-LINE SUBTITLES:
- Support subtitles with multiple text lines
- Preserve newlines in text field
- When saving, write each line on separate line
- Do not merge lines into single line

UTF-8 REQUIREMENTS:
- Read SRT files with UTF-8 encoding
- Handle UTF-8 BOM if present
- Write SRT files with UTF-8 encoding
- Vietnamese characters must work correctly

ERROR HANDLING:
- Create clear, descriptive errors
- Do not silently ignore corrupted subtitle blocks
- Avoid catching every exception and hiding actual problem
- Raise ValueError or custom exception with clear message
