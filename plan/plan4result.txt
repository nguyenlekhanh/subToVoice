9. Video Service implementation
- VideoMetadata dataclass: path, width, height, fps, frame_count (Optional[int]), duration_ms, has_audio, first_frame_path
- check_ffmpeg(): Uses shutil.which for ffmpeg and ffprobe
- load_video_metadata(): Runs ffprobe -v error -show_streams -show_format -of json, parses JSON
- parse_fps(): Handles rational FPS like "30000/1001" -> 29.97
- parse_duration(): Converts seconds string to milliseconds
- Frame count: Uses nb_frames from stream, None if missing (not 0)
- Duration: Prefers stream duration, falls back to format duration
- Audio detection: Checks for any audio codec_type stream
- extract_first_frame(): Runs ffmpeg -ss 0 -i input -frames:v 1 -y output.png
- load_video_with_frame(): Combined operation, saves frame to temp dir with UUID filename
