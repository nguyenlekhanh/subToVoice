- Added GUI-independent services/piper_service.py.
- Added frozen PiperVoice with:
  name
  model_path
  config_path
  source
  language
  dataset
  phoneme_type
  sample_rate
  num_speakers
- Discovery searches config/piper/ first and config/piper-en/ second.
- Discovery recursively accepts regular files whose extension is .onnx.
- A voice is valid only when its matching <voice>.onnx.json regular file exists and parses as JSON.

- Unexpected but parseable non-dictionary JSON yields safe empty metadata rather than crashing discovery.
- Language is taken from language.code when present and falls back to espeak.voice.
- Absolute resolved model and configuration paths identify unique voices and prevent duplicate physical entries.

- No audio is generated.
- No TTS synthesis is implemented.
