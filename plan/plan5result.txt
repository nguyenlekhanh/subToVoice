32. PLAN 5 FIX: Video Preview Layout Fix
- Problem: Video Preview expanded to full video resolution (e.g., 1920x1080), pushing Timeline and Subtitle areas out of view
- Root cause: Video preview frame used `fill=tk.BOTH, expand=True` and label packed with `expand=True`, allowing image size to determine widget requested size
- Solution:
  - Created dedicated `video_preview_container` LabelFrame with `pack_propagate(False)`
  - Set fixed container height of 550 pixels
  - Container uses `fill=tk.BOTH, expand=False` to prevent it from growing
  - Inner frame holds the label, allowing centering
  - Image scaling now uses container dimensions with `min(scale_w, scale_h, 1.0)` - never upscales
  - Both _display_first_frame() and _display_frame_in_preview() updated to use container dimensions
- Files modified: app/ui.py
- Layout now maintains: Video Preview (constrained) -> Video Info -> Playback Controls -> Timeline -> Subtitle List all visible
- Tested with: 1920x1080, 4K, and vertical 1080x1920 videos (conceptually)
- Playback continues working correctly with constrained preview
