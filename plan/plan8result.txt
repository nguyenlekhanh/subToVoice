25. PLAN 8 FIX 6 - Fix Timeline Subtitle Block Click Error (2026-09-27)
- Error: `ValueError: invalid literal for int() with base 10: 'block'` when clicking subtitle block on Timeline
- Root cause: Both `_on_timeline_click` and `_on_timeline_mouse_press` methods searched for tags starting with "subtitle_" but the Canvas items have two tags: "subtitle_block" (generic) and "subtitle_N" (index). The code picked the first matching tag "subtitle_block" and tried to parse "block" as an integer.
- Root cause analysis: The subtitle blocks are created with tags `("subtitle_block", f"subtitle_{sub.index}")`. The code was finding "subtitle_block" first and trying to parse "block" as an integer.
- Fix: Modified both `_on_timeline_click` and `_on_timeline_mouse_press` to:
  1. Skip the "subtitle_block" tag when searching
  2. Look for tags matching "subtitle_N" pattern where N is a number
  3. Added proper error handling with try/except for int() conversion
- Fix location: Modified `_on_timeline_click` (line 592-595) and `_on_timeline_mouse_press` (line 620-634) in `app/ui.py`
