PLAN 4 REQUIREMENTS

Plan Number: 4
Plan Name: Load Video + Video Metadata + First Frame

Goal: Implement video loading, metadata reading, audio detection, first frame extraction, and display in the GUI.

Required Scope:
- Load Video button functionality
- FFmpeg detection (shutil.which)
- FFprobe detection (shutil.which)
- Video metadata reading via ffprobe (JSON output)
- FPS parsing (rational values like 30000/1001)
- Duration conversion to milliseconds
- Frame count handling (None if unknown, not 0)
- Audio stream detection
- First frame extraction via FFmpeg
- First frame display in Video Preview area (preserve aspect ratio)
- Video information display near preview
- Background worker for all FFmpeg/FFprobe operations
- Queue/root.after UI updates
- Video state in application state

Dependencies:
- Python standard library only (subprocess, json, shutil, threading, queue, pathlib, tempfile, uuid, tkinter)
- No Pillow unless absolutely necessary (try PhotoImage first)
- FFmpeg and FFprobe must be available in system PATH (not bundled)

Detailed Requirements:

VIDEO SERVICE (services/video_service.py):
- VideoMetadata dataclass with: path, width, height, fps (float), frame_count (int or None), duration_ms (int), has_audio (bool), first_frame_path (str)
- check_ffmpeg() -> bool: Verify ffmpeg and ffprobe are available
- load_video_metadata(file_path) -> VideoMetadata: Run ffprobe, parse JSON, extract info
- extract_first_frame(file_path, output_path) -> bool: Run ffmpeg to extract first frame
- parse_fps(fps_str) -> float: Parse rational FPS like "30000/1001"
- parse_duration(duration_str) -> int: Convert seconds to milliseconds

UI CHANGES (app/ui.py):
- Update _create_video_preview to support image display (Label with PhotoImage)
- Add metadata display area below or beside video preview
- _on_load_video: File dialog with video filters, start background worker
- Background worker: call video_service functions, put result in queue
- Main thread: update UI with first frame image, metadata labels, status
- Status messages: "Loading video...", "Reading video metadata...", "Extracting first frame...", "Video loaded", "Failed to load video: <error>"
- Preserve aspect ratio when displaying first frame
- Handle missing FFmpeg/FFprobe gracefully
- Handle invalid video files gracefully
